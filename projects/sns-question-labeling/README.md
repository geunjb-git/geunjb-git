# SNS 질문 라벨 검토·수정과 콘텐츠 반응 EDA

SNS 질문을 유형별로 비교하기 위해 AI의 초기 분류를 문맥에 맞게 검토·수정하고, 분류한 질문으로 사용자 반응 차이를 살펴본 팀 프로젝트 사례입니다.

**담당 경험:** 질문 문맥 검토와 카테고리 수정에 참여했습니다. 아래 EDA와 운영 제안은 팀 발표 자료와 저장된 분석 결과를 요약했습니다.

[라벨 수정 예시](label_revision_examples.csv) · [EDA 집계표](category_eda_summary.csv) · [요약 노트북](labeling_and_eda_summary.ipynb) · [자료 출처와 지표 정의](SOURCES.md)

## 1. 왜 질문을 분류했나

익명 투표 SNS에서 질문 콘텐츠에 따라 참여와 후속 반응이 어떻게 달라지는지 확인하고자 했습니다. 개별 질문을 같은 기준으로 묶기 위해 주제 카테고리가 필요했습니다.

질문 문구를 정리한 분류 파일은 **3,898개 질문, 8개 대분류**로 구성했습니다. 같은 단어가 들어가더라도 질문이 묻는 핵심 의미에 따라 분류했습니다.

## 2. AI 분류 이후 어떻게 검토했나

| 단계 | 작업 |
| --- | --- |
| 기준과 예시 준비 | 팀에서 카테고리 정의서와 표본 라벨을 준비했습니다. |
| AI 초기 분류 | 정의서와 예시를 바탕으로 질문의 주제 라벨을 분류했습니다. |
| 문맥 검토·수정 | 질문이 묻는 대상과 의미를 확인하고, 경계가 모호하거나 맞지 않는 카테고리를 조정했습니다. |
| 분석에 활용 | 질문 라벨을 투표·읽음·초성 열람 등 사용자 반응 집계와 연결했습니다. |

### 파일에서 확인한 수정 전후 예시

| 질문 | 초기 라벨 | 수정본 라벨 |
| --- | --- | --- |
| 음식 취향이 잘맞는 사람은? | 관계·친밀도 | 생활·취향 |
| 같이 동물원 가고 싶은 사람은? | 연애·이성호감 | 관계·친밀도 |
| 음악 취향이 가장 잘 맞는 친구는? | 관계·친밀도 | 생활·취향 |

예를 들어 음식·음악 취향이 맞는지를 묻는 질문은 두 사람의 관계 자체보다 **선호와 취향**에 초점을 맞춰 분류했습니다. 동물원 동행 질문은 함께하고 싶은 관계의 의미를 기준으로 정리했습니다. 이 설명은 라벨 차이를 이해하기 위한 해설입니다.

위 표는 초기 AI 분류 출처가 표시된 CSV와 수정본을 대조한 사례입니다. 개인별 작업량으로 제시하지 않았으며, 검토·수정 과정에 참여한 경험을 중심으로 정리했습니다.

### 사용한 8개 대분류

| 카테고리 | 판단 기준 |
| --- | --- |
| 성격·기질 | 성향과 태도 등 비교적 지속적인 성격 특성 |
| 생활·취향 | 일상 습관이나 반복되는 행동·선호 |
| 외모·비주얼 | 얼굴·체형·스타일 등 외적 요소 |
| 능력·재능 | 특정 일을 잘하는 능력이나 재능 |
| 연애·이성호감 | 설렘·데이트 등 로맨틱한 감정이 핵심인 질문 |
| 관계·친밀도 | 비연애 관계의 친밀감·신뢰·함께하고 싶은 마음 |
| 이미지·평판 | 구체적 속성보다 종합적인 인상이나 평판 |
| 상상·유머 | 가정한 상황의 재미나 상상이 핵심인 질문 |

## 3. EDA에서 무엇을 확인했나

다음 표는 팀 노트북의 **저장된 카테고리 집계**에서 건수와 비율을 다시 계산해 정리했습니다. 원시 로그를 새로 조회한 결과와는 구분합니다.

| 카테고리 | 투표 건수 | 원본 질문 ID당 평균 투표 | 읽음 비율 | 읽음 대비 초성 열람 비율 |
| --- | --- | --- | --- | --- |
| 연애·이성호감 | 106,213 | 287.8회 | 58.14% | 13.71% |
| 관계·친밀도 | 173,983 | 218.6회 | 56.78% | 12.32% |
| 외모·비주얼 | 140,451 | 279.8회 | 56.47% | 9.71% |
| 이미지·평판 | 165,475 | 221.8회 | 55.11% | 7.98% |
| 상상·유머 | 104,926 | 234.2회 | 56.32% | 7.90% |
| 성격·기질 | 241,108 | 320.2회 | 54.49% | 6.61% |
| 능력·재능 | 132,366 | 331.7회 | 53.73% | 5.31% |
| 생활·취향 | 137,137 | 185.8회 | 55.17% | 5.12% |

여기서 투표 건수는 이미 발생한 투표 기록 수입니다. 노출 대비 투표 전환율을 뜻하지 않습니다. 평균 투표의 분모는 원본 `question_id`의 고유 개수이며, 정규화된 질문 문구 3,898개와 단위가 다릅니다.

### 관찰한 차이

- **참여 규모와 후속 반응의 순위가 달랐습니다.** 능력·재능과 성격·기질은 원본 질문 ID당 평균 투표가 높았고, 연애·이성호감과 관계·친밀도는 읽음 대비 초성 열람 비율이 높았습니다.
- **읽음 비율보다 초성 열람 비율에서 차이가 뚜렷했습니다.** 저장된 집계에서 읽음 비율은 약 54%에서 58% 사이였지만, 읽음 대비 초성 열람 비율은 약 5%에서 14% 사이였습니다.

질문을 많이 사용했다는 이유만으로 후속 반응까지 높다고 판단하기 어려웠습니다. 질문의 목적에 맞춰 참여 규모와 후속 반응을 함께 비교할 필요가 있다고 정리했습니다.

## 4. 결론과 운영 제안

팀에서는 중분류별 초성 열람·답장 반응까지 비교해 질문의 역할을 나누고, 신규 사용자의 이용 단계에 맞춘 질문 구성과 반응이 낮은 문항의 재설계를 제안했습니다.

이 자료에서 보여주는 결과는 **분류 기준을 적용한 데이터 검토와 EDA에서 관찰한 차이**입니다. 질문 배치나 문항 재작성은 운영 제안이며, 실제 적용 효과는 별도 검증이 필요합니다. 초성 열람 상태를 실제 유료 결제로 해석하지 않았습니다.
