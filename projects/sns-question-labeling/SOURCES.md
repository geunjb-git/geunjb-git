# 자료 출처와 지표 정의

## 자료와 담당 범위

이 폴더는 SNS 고급 팀 프로젝트 전체 중 질문 라벨 검토·수정과 관련 EDA를 요약한 공개 사례입니다. 정봉근은 질문 문맥 검토와 라벨 수정 작업에 참여했습니다. 카테고리 EDA와 최종 운영 제안은 팀 결과입니다. 라벨 변경 예시는 중간 분류 파일 간 대조를 사용하고, EDA는 별도로 저장된 팀 분석 집계를 사용했습니다.

| 사용 자료 | 이 폴더에서의 용도 |
| --- | --- |
| `preprocessing/member_d/question_label_final.csv` | 초기 라벨과 초기 분류 출처 확인 |
| `preprocessing/member_d/question_label_final_updated.csv` | 같은 질문의 카테고리 변경 사례 확인 |
| `sns_analysis/analyses/member_a/eda_v3.ipynb`의 저장된 집계 출력 | 셀 269의 투표·읽음·초성 열람 건수, 셀 273의 원본 질문 ID 수와 투표 수 |
| 기존 팀 발표 자료의 질문 분석·전략 부분 | 분류 절차, 중분류별 반응 해석, 질문 구성·재작성 제안 |

참고한 발표 자료는 `SNS_지속이용_서비스개선_디자인통일_43장_final.pptx`라는 제목의 Canva 자료입니다. 확인 당시 실제 구성은 59페이지였으며, Canva 페이지 순서 기준 24~25페이지는 분류 기준·절차, 26~33페이지는 카테고리 EDA와 해석, 43페이지는 질문 운영 제안입니다.

## 단위와 분모

| 공개 CSV 컬럼 | 의미·계산식 |
| --- | --- |
| `vote_count` | 해당 카테고리의 투표 기록 수. 원본 출력의 `exposure_cnt`·`vote_cnt`를 투표 건수로 명확히 표기 |
| `read_count` | `has_read_snapshot == True`로 표시된 건수 |
| `initial_open_count` | `opened_times_snapshot > 0`으로 표시된 건수 |
| `original_question_id_count` | 카테고리 내 원본 `question_id` 고유 개수 |
| `votes_per_original_question_id` | 투표 건수 / 원본 질문 ID 고유 개수 |
| `read_rate_pct` | 읽음 표시 건수 / 투표 건수 × 100 |
| `initial_open_per_vote_pct` | 초성 열람 표시 건수 / 투표 건수 × 100 |
| `initial_open_relative_to_read_pct` | 초성 열람 표시 건수 / 읽음 표시 건수 × 100 |

카테고리 8행의 투표 수 합계는 1,201,659건, 원본 질문 ID 수 합계는 4,751개입니다. 정규화된 질문 문구 분류 파일의 3,898행과 원본 질문 ID 단위는 서로 다릅니다.

읽음과 초성 열람은 저장 시점의 상태입니다. 이 표는 행동이 발생한 정확한 시각이나 유료 결제 여부를 복원하지 않습니다. 특히 기존 발표 자료의 일부 ‘결제 전환’ 표현은 여기서 초성 열람 비율로 정리했습니다. 실제 결제자 수나 결제 매출은 집계하지 않았습니다.

## 라벨 변경 사례

같은 질문 문구를 키로 초기 분류 파일과 수정본을 대조했습니다. 공개한 3개 문장은 모두 초기 파일의 출처가 `AI 문맥 판단`이고, 수정본에서 카테고리가 바뀐 사례입니다. 초기 출처는 이후 검토·수정을 누가 했는지나 개인별 최종 작업량을 나타내지 않습니다.

## 요약 노트북의 실행 범위

공개 CSV는 저장된 팀 집계에서 추출한 값입니다. 요약 노트북은 해당 CSV에서 비율과 표를 다시 계산합니다. BigQuery 원시 로그의 추출·정제·분류표 연결 전체를 재실행하는 노트북이 아닙니다. 운영 개선 방향은 탐색 결과를 바탕으로 한 제안으로 제시했습니다.
