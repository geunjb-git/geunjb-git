# 공개본 변경 내용

1. 할인 고객 797명, 12월 고유 갱신 고객 368명, 연간권 기록 고객 136명으로 대상을 통일했다. 갱신자 중 비중 37.0%와 전체 코호트 중 비중 17.1%를 구분했다.
2. 886명·429명·144명은 정상가를 포함한 11월 전체 고객 기준으로 남겨 차이의 원인을 설명했다.
3. 두 상품 기록이 있는 13명은 연간권 기록 그룹에 한 번만 포함해 429/232/136명의 배타적 그룹을 구성했다.
4. 마스터의 원래 갱신 플래그와 12월 갱신 여부를 별도 변수로 분리했다.
5. 콘텐츠 시작·완료·경험 난이도를 첫 결제 후 30일 범위에서 재계산했다. 완주율 분자·분모와 미정의 고객 처리 기준을 명시했다.
6. 활동 날짜 수·최근 활동 간격은 제공된 30일 고객 마스터 값임을 표시했다.
7. 원본 분류 모형의 타깃·시간 범위·저장 출력 불일치를 검토 문서로 설명했다. 기존 모델 점수를 새 타깃의 성과로 옮기지 않았다.
8. 실행한 공개 노트북, 집계 JSON, 그래프, 재계산 함수와 실행 방법을 추가했다. 개인 PC 경로·사용자별 출력·원본 CSV는 공개하지 않았다.

원본 추가분석 노트북과 로컬 데이터는 수정하지 않았다. 기존 발표 PDF/PPT는 이 묶음에서 수정하지 않았으며, 발표본에도 숫자를 반영할 때 같은 모집단과 기간을 적용해야 한다.
