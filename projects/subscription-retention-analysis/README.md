# 할인 유입 고객의 재구독 행동 분석

**2022년 11월 할인 유입 고객 797명 중 368명이 12월에 갱신했고, 그중 136명(37.0%)에게 연간권 기록이 있었습니다.**

개인 프로젝트로 고객별 로그 집계와 행동 비교를 수행했습니다. 행동 지표는 원본 `plan15920_user_level_data.csv`의 정의를 유지하고, 갱신 인원은 할인 코호트의 12월 기록으로 맞췄습니다.

[웹 포트폴리오](https://geunjb-git.github.io/geunjb-git/#subscription) · [발표자료 PDF](../../docs/files/subscription-retention.pdf) · [분석 노트북](subscription_retention_analysis.ipynb) · [지표 정의](metric_notes.md)

![할인 유입 고객의 갱신 흐름](assets/discount_cohort_funnel.png)

## 문제와 분석 대상

할인으로 유입된 고객은 가격에만 민감한 고객일까요? 여러 달을 합친 제공 마스터에서 할인 고객의 갱신율은 낮았지만, 11월 고객의 학습 행동에서는 다른 특징을 확인했습니다.

- 11월 첫 결제·15,920원 플랜: 정상가 89명, 할인 797명
- 갱신 집계: 할인 고객 797명의 2022년 12월 갱신 기록
- 행동 비교: 제공 마스터의 콘텐츠 수·고객별 완주율·30일 활동 지표
- 도구: Python, pandas, matplotlib

## 갱신 흐름

| 단계 | 고객 수 | 비율 기준 |
|---|---:|---|
| 11월 할인 유입 | 797명 | 분석 코호트 |
| 12월 갱신 기록 | 368명 | 할인 유입 고객의 46.2% |
| 12월 연간권 기록 | 136명 | 갱신자의 37.0%, 할인 유입 전체의 17.1% |

연간권 기록은 12월 79,200원 상품의 갱신 기록이 한 번 이상 있는 고객입니다. 최종 보유 상품을 확정한 지표는 아닙니다.

기존 `797 → 429 → 144`에서 429명·144명은 정상가까지 포함한 11월 전체 886명 기준이었습니다. 할인 고객만으로 대상을 통일해 `797 → 368 → 136`으로 정정했습니다.

## 원본 CSV 기준의 학습 행동

![원본 CSV 정의의 콘텐츠 완주율](assets/learning_behavior_comparison.png)

| 11월 고객 | 고객 수 | 고객별 콘텐츠 완주율 평균 | 30일 평균 활동 이벤트 수 |
|---|---:|---:|---:|
| 정상가 | 89명 | 14.2% | 337.5 |
| 할인 | 797명 | 30.0% | 445.1 |

완주율은 원본 `user_content_completion_rate(%)` 열을 평균했습니다. 
콘텐츠 완주율은 원본 CSV의 고객별 완주율을 평균한 값입니다. 콘텐츠를 시작하지 않은 고객에게 기록된 0%도 평균에 포함했습니다.

원본의 콘텐츠 수와 30일 활동 지표는 관찰 범위가 같다고 가정하지 않습니다. 집단 차이를 회고적으로 비교하며 미래 갱신 예측 성능이나 인과효과로 제시하지 않습니다.

## 상품 기록별 집단 비교

월간권 기록 245명과 연간권 기록 136명 중 13명이 두 집단에 모두 속합니다. 따라서 429명·245명·136명을 상호 배타적인 집단으로 합산하지 않습니다. 원본 탐색의 상품 기록별 비교를 보존했으며, 노트북에서 원본 CSV 지표로 비교했습니다.
13명의 경우에는 먼저 월간권으로 추가 구독 후 12월안에 연간권을 추가로 구매한 고객입니다.

## 제안과 해석 범위

학습 활동이 이어지고 여러 콘텐츠를 이용하는 고객에게 연간권을 안내하는 가설을 제안했습니다. 실제 활용 시점까지 관찰된 행동으로 대상을 정하고, 비교 실험으로 전환·비용·후속 유지율을 확인해야 합니다. 실제 CRM 실행이나 매출 개선 성과를 주장하지 않습니다.

제공 마스터 전체의 정상가 갱신율 63.15%, 할인 갱신율 53.12%는 여러 달의 별도 집계입니다. 마스터 `renewed`와 이번 12월 갱신 판정은 다른 정의입니다. 기존 모형 탐색은 [모델 검토](model_review.md)에 구분했습니다.

## 파일과 실행

- `analysis.py`: 입력 검증, 할인 코호트의 12월 갱신 집계, 원본 CSV 행동 비교와 그래프
- `subscription_retention_analysis.ipynb`: 문제 정의, 집계 확인, 시각화와 해석
- `aggregate_results.json`: 개인별 기록을 제외한 집계
- `metric_notes.md`, `model_review.md`, `changes.md`: 지표와 해석 범위

공개하지 않은 원본 데이터가 있는 환경에서 아래와 같이 실행합니다.

```text
data/
  15920_1개월플랜_분석/plan15920_user_level_data.csv
  renew_subscription_df.csv
```

```bash
python -m pip install -r requirements.txt
python analysis.py
```

다른 위치의 데이터는 `SUBSCRIPTION_DATA_DIR` 환경변수로 지정합니다. 원본이 없으면 전체 재실행은 불가능하며 공개된 집계·그래프·노트북으로 분석 흐름을 확인할 수 있습니다.
