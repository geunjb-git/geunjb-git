# 할인 유입 고객의 재구독 행동 분석

**할인 유입 고객을 하나의 집단으로 판단하기보다, 갱신·연간권 전환 고객의 학습 행동을 나누어 살펴본 개인 프로젝트입니다.**

## 확인한 질문

2022년 11월 할인 프로모션으로 유입된 고객은 단순히 가격에 민감한 고객이었을까요? 갱신과 연간권 전환 고객이 어떤 행동 차이를 보이는지 분석했습니다.

## 분석 과정

- 학습 시작·완료·페이지 진입 등 여러 이벤트 로그를 통합했습니다.
- 첫 결제 후 30일 행동을 고객 단위로 집계했습니다.
- 활동일수, 최근 활동성, 콘텐츠 탐색·시작·완료, 경험한 난이도 수와 완주율을 구성했습니다.
- 갱신과 상품 전환 집단의 행동을 비교하고 Random Forest의 예측 기여도를 참고했습니다.

## 확인한 결과

| 단계 | 고객 수 | 비율 기준 |
|---|---:|---|
| 11월 할인 유입 | 797명 | 해당 할인 유입 코호트 |
| 12월 갱신 | 429명 | 할인 유입 코호트 중 갱신 고객 |
| 연간권 전환 | 144명 | 갱신 고객 429명 중 33.6% |

연간권 전환 고객은 이탈·월간권 갱신 고객보다 콘텐츠 탐색, 활동일수와 완주율이 더 높은 양상을 보였습니다. 최근 활동성과 콘텐츠 다양성을 재구독 관련 신호로 검토했습니다.

## 활용 제안

학습 활동이 이어지고 여러 콘텐츠를 탐색하는 고객에게 연간권 안내를 제안했습니다. 혜택 조회와 결제 페이지 행동 등 추가 로그를 수집하고, 안내 전략의 실제 전환·재구독 효과는 후속 실험으로 확인할 과제로 남겼습니다.

## 해석의 한계

행동 차이와 모델의 예측 기여도는 인과효과를 뜻하지 않습니다. 업셀링이나 재구독 개선 성과는 실제 실행 결과로 주장하지 않습니다. 지표를 비교할 때 전체 고객과 특정 할인 코호트의 모집단을 구분해야 합니다.

## 공개 범위

이 페이지는 분석 요약입니다. 교육용 고객 원본 로그와 사용자별 데이터는 포함하지 않습니다.
