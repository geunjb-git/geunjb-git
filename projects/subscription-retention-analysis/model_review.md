# 기존 모형 탐색의 해석 범위

원본 추가 분석에서 Random Forest 등의 모형을 탐색했습니다. 현재 공개 노트북은 코호트 집계와 원본 CSV 행동 비교를 제공하며 모형의 재현·재검증 결과를 주장하지 않습니다.

- 원본 마스터의 renewed와 이번 12월 갱신 여부는 서로 다른 타깃입니다.
- 원본 CSV 콘텐츠 지표와 30일 활동 지표의 집계 범위는 동일하다고 가정할 수 없습니다.
- 관찰 종료와 갱신의 선후관계를 정리하지 않은 집단 비교를 미래 갱신 예측 성능으로 제시하지 않습니다.
- 원본 모형의 F1-score, ROC-AUC와 변수 중요도는 별도 탐색 결과이며 원인 규명의 근거가 아닙니다.
- 후속 모형 검증에는 예측 시점까지 관찰한 특징, 이후의 명확한 타깃 기간, 시간 순서에 따른 평가가 필요합니다.

현재 웹 포트폴리오는 검증되지 않은 예측 성능이나 실제 CRM 개선 성과를 제시하지 않습니다.
