# 공개용 정리 내용

1. 세 탐색 노트북의 핵심 내용을 한 개의 읽기 순서로 구성했다.
2. 전체 신청자 결제율과 방문자 결제율을 구분했다. 방문자 결제율 분자는 방문 기록이 있는 결제자로 제한했다. 기존 일부 표의 64.15%/27.00%를 44.15%/22.46%로 수정했다.
3. 3일 이상 방문 구간을 정확히 표시했다. 구간별 비교에서의 묶음과 회귀의 원래 방문일수 사용을 구분했다.
4. 기본 회귀를 원본 입력 파일로 재실행해 기존 연도 오즈비 약 0.374를 확인했다.
5. 실행 오류·중복 탐색 셀·사용자별 레코드 출력·특정 고객 ID·개인 PC 절대경로·비공개 helper 의존성을 제거했다.
6. 입력 스키마, 고객 결합 단위, 결측 처리, 관찰기간·결제 전후 순서의 한계를 명시했다.
7. 원본 CSV를 포함하지 않고 집계 결과와 그래프만 공개본에 넣었다.
8. 투표 → 로그 연결 → A/B 테스트 → CRM이라는 원래 제안 흐름을 유지했다. 실행하지 않은 성과를 추가하지 않았다.

로컬 원본 파일은 수정하지 않았다. 기존 발표 PDF는 이 묶음에 포함하지 않았다. 발표 자료에 방문자 결제율 64.15%/27.00%가 남아 있다면 수정 후 추가해야 한다.
