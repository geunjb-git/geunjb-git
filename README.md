# 정봉근

고객 행동과 결제 데이터를 분석하고, 다음에 확인할 질문과 액션을 정리합니다.

고객상담 경험을 바탕으로 데이터 분석을 공부하고 있습니다. 프로젝트에서 지표의 의미와 비교 기준을 정의하고, 데이터 정제·검증부터 분석 결과 공유까지 진행했습니다.

**분석 도구**  SQL · Python · BigQuery · dbt · Looker Studio

## 분석에서 중요하게 보는 것

- 비교 대상과 지표의 분모를 먼저 확인합니다.
- 결측과 0을 구분하고 집계 단위와 조인 정합성을 점검합니다.
- 관측된 관계와 인과효과를 구분하고, 추가로 수집할 데이터와 검증할 가설을 제안합니다.
